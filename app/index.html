주소로 소개

주소로는 ‘원하는 사이트로 가는 가장 빠른 길’을 목표로 하는 링크 내비게이션입니다. 매일 쓰는 포털·검색부터 뉴스·미디어, 쇼핑, 커뮤니티·SNS, 교육·학습, 여행·지도, 개발·도구, 동영상·OTT, 금융·은행, AI·챗봇, 정부·민원, 논문·학술자료까지 54개 카테고리에 걸쳐 1,900여 개의 사이트를 안내합니다. 찾아야 할 사이트의 이름이 가물가물할 때도 카테고리를 따라가면 목적지가 나옵니다.

주소로의 모든 목록은 인기순으로 정렬됩니다. 같은 종류의 서비스가 여러 개일 때 어떤 곳이 가장 많이 쓰이는지 순위로 비교할 수 있고, 사이트 이름이나 로고를 누르면 바로 이동합니다. 검색창에 이름 일부나 주소를 입력하면 전체 카테고리에서 즉시 찾아주므로 북마크를 뒤지는 것보다 빠르게 도착합니다.

자주 가는 곳은 찜하기로 저장해 나만의 경로를 만들 수 있습니다. 브라우저 시작 페이지를 주소로로 설정해 두면 아침 뉴스부터 업무 도구, 저녁의 쇼핑과 여가까지 하루의 이동이 한 페이지에서 시작됩니다. 아래 카테고리별 안내 페이지와 가이드에서는 분야별 사이트 목록과 고르는 요령도 정리해 두었습니다.

무료로 제공됩니다. 별도의 비용 없이 모든 카테고리와 사이트 안내를 이용할 수 있습니다.
원하는 사이트를 빠르게 찾으려면?
검색창에 이름 일부나 주소를 입력하면 전체 카테고리에서 즉시 찾아줍니다. 자주 가는 곳은 찜하기로 저장해 나만의 경로를 만들 수 있습니다.
사이트 순위는 어떤 기준인가요?
같은 종류의 서비스가 여러 개일 때 어떤 곳이 많이 쓰이는지 인기순으로 비교할 수 있도록 정렬됩니다. 이름이나 로고를 누르면 해당 사이트로 바로 이동합니다.
시작 페이지로 쓰기 좋나요?
